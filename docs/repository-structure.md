# 저장소 구조 규칙

코드는 실행·배포의 대상인지, 그 대상을 구성하는 라이브러리인지에 따라 배치한다.

| 폴더 | 역할 | 예시 |
| --- | --- | --- |
| `apps/` | 사용자나 운영자가 실행·배포하는 프로그램 | CLI, 웹, API 서버 |
| `packages/` | 프로그램에서 가져다 사용하는 라이브러리 | Core, Runtime 계약, Adapter, UI 컴포넌트 |

## 기본 원칙

- 사용하는 앱의 개수나 npm 배포 여부가 아니라 코드의 역할로 분류한다. 한 앱에서만 쓰는 라이브러리도 `packages/`에 둘 수 있고, npm으로 배포하는 CLI도 `apps/`에 둔다.
- 특정 화면이나 명령에만 필요한 코드는 해당 앱 내부에 둔다.
- 독립된 책임이나 의존 경계가 필요할 때 패키지로 분리한다.
- 디렉터리와 패키지는 실제 코드를 추가할 때 생성한다. 미래의 구성을 예상해 빈 폴더를 만들지 않는다.

Core·Runtime·Paseo Adapter의 의존 경계는 [ADR 0005](adr/0005-local-development-cli-boundary.md)을 따른다.
